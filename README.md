# Real Trading Game

A Solana-themed trading game inspired by the classic Dino game, built with HTML, CSS, and JavaScript.

## Features

- **Trading Theme**: PnL system with +$10 for successful jumps, -$10 for collisions
- **Solana Integration**: Solana logo as the main character
- **Candle Obstacles**: Red candlesticks with varying heights and wick lengths
- **Withdraw System**: Withdraw button with fun messages
- **Token Information**: $RT token ticker and contract address
- **Responsive Design**: Works on desktop and mobile devices

## Game Controls

- **Jump**: SPACE or ↑ arrow key
- **Duck**: ↓ arrow key (for flying candles)

## Token Information

- **Token**: $RT
- **Contract**: GGQqRJPUfzJY9TsSZVTjgdF8YLWXfpuoZ1fDeMWtpump

## How to Play

1. Press START to begin trading
2. Jump over red candlesticks to earn $10
3. Avoid collisions to prevent losing $10
4. Use duck for flying candles
5. Try to maximize your PnL!

## Setup

1. Clone the repository
2. Open `index.html` in a web browser
3. Or run a local server: `python -m http.server 8000`

## Technologies Used

- HTML5
- CSS3 (with animations and grid backgrounds)
- JavaScript (ES6+)
- SVG graphics
- JSON database for candle properties
