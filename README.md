# Dino Jump Game

A single-screen landing page featuring a playable dinosaur jumping game inspired by Chrome's offline dinosaur game.

## How to Play

1. Open `index.html` in any modern web browser
2. Press the "START GAME" button or press the SPACE key to begin
3. Press SPACE to make the dinosaur jump over obstacles
4. Try to get the highest score possible!

## Controls

- **SPACE**: Jump / Start Game
- **Touch Screen**: Tap to jump / start (for mobile devices)
- **START / PLAY AGAIN buttons**: Start a new game

## Features

- Single-screen design with no scrolling
- Simple retro "degenish" styling with green terminal-like aesthetics
- Score tracking with increasing difficulty
- Responsive design for different screen sizes
